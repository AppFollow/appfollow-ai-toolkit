# Knowledge base (static team context)

Repo-canonical for GTM OS: agents read these files directly at the start
of every run (no Guru cards are registered for this repo yet — see
`config/system.yaml → guru_knowledge`; when GTM context moves to Guru,
adopt the leadership-os no-fallback rule).

- `marketing-team.md` — the Marketing team map: who owns what, how
  part-timers are routed, addressing rules for the Actions Check
- `kpi-weekly-intent.md` — the TARGET shape of the future Marketing
  Weekly KPI digest (Agent 2 is a stub; this is intent, not
  implementation)

Difference from `memory/`: `knowledge/` is maintained by humans and
changes rarely; `memory/` is written by agents on every run.
